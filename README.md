# SCKI

## Create a virtual environment
```bash
python -m venv .venv
```

## Activate the virtual environment
```bash
.venv\Scripts\activate
```

## Install dependencies
```bash
pip install -r requirements.txt
```

## Start Marimo server
```bash
marimo edit
```

## Start Marimo server (headless)
```bash
marimo edit --headless
```
